# Brazil Budget Amendment Analysis Project

This project analyzes Brazil's "Orçamento Paralelo" (Parallel Budget) system, focusing on the relationship between budget amendments and political power dynamics.

## Work Completed

Based on the analysis of the original index.html file, we identified several key aspects of Brazil's budget amendment system:
- Three main types of amendments: Individual, Bancada (Regional), and Relator (Budget Rapporteur)
- How these amendments serve as tools for political survival and coalition building
- The power dynamics involved in distributing budget resources

We then proposed 7 project ideas inspired by The Pudding's data visualization approach:
1. "Votes for Dollars: Amendment vs. Voting Patterns"
2. "Power Layers: Individual, Bancada, Relator"
3. "Political Survival Simulator"
4. "Clientelism Flow Network"
5. "Capture Timeline: 1988 to Now"
6. "Risk Matrix: Corruption Exposure by Amendment Type"
7. "Amendment Typology Explorer"

For project #5 "Capture Timeline: 1988 to Now", we identified the need for historical data sources, technical tools, and content research.

We developed a detailed workflow for project #1 "Votes for Dollars: Amendment vs. Voting Patterns" with 7 phases:
1. Data Collection
2. Data Processing
3. Analysis
4. Visualization Design
5. Development
6. Testing
7. Content Creation

We executed Phase 1: Data Collection, gathering amendment data from SICONV/Portal da Transparência, voting records from Câmara dos Deputados and Senado, election cycle data from TSE, and municipal demographic data from IBGE.

The collected data has been structured into standardized CSV files ready for processing:
- amendments.csv
- votes.csv
- representatives.csv
- municipalities.csv
